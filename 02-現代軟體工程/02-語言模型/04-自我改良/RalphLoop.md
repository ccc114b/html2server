以下程式碼稱為 Ralph Loop

是 Geoffrey Huntley 用辛普森家庭中一個稱為 Ralph Wiggum 的小男孩來命名的，那個小男孩『無比樂觀，永遠努力』

```sh
while :; do cat PROMPT.md | claude-code ; done
```

你只要一開始將 PROMPT.md 寫好，然後他就會一直循環呼叫 claude-code ，直到完成任務（寫好程式）為止。

結果這個做法後來影響巨大，Anthropic 的 Claude Code 負責人 Boris Cherny 將 Geoffrey Huntley 的五行腳本正式收編，推出了官方 Ralph-Wiggum 外掛。

在 2025 年底，Boris Cherny 親口承認：過去三十天內，自己對 Claude Code 專案的貢獻，100% 都是由 Claude Code 自己完成的！
