AI 時代要學 openclaw ，其實已經不需要買書了

你需要做的就只有下列事情

1. 先創建一個安全的環境 (虛擬機或開 guest 賬號）

2. 裝好 openclaw

3. 用 openclaw onboard 設定好模型 (我目前用 openai-codex/gpt-5.3-codex) 與其他選項

4. 開始用 openclaw ，有任何不會用都直接問他怎麼用（如果你還想學的話？） 如果你不想學，就直接叫他做就行了（他比你強）

5. 關機離開後，下次再進來，用 openclaw tui 指令，就可以接著上次的對話繼續使用了。

剩下的，都是 openclaw 的事情了 ....

(重點是，openclaw 太強了，風險很高，小心他超出權限，甚至去刷你信用卡）

(別讓他知道你的機密資訊，最好也別登入和金錢有關的網站，重要的網站也盡量別和 openclaw 在同一環境下使用)

(但還是有風險，如果你登入自己的 gmail ，然後曾經在 gmail 中有帳號密碼或信用卡資訊，還是有可能被 openclaw 看到）

(所以最好還是使用虛擬機，然後共享資料夾）
